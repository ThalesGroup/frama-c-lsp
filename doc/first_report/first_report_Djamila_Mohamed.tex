\section{Introduction}
\subsection{Thales DIS, IBS}
Thales Digital Identity and Security is the global business unit (GBU) of Thales which operates in the field of secure software, providing biometrics and encryption solutions. Within the DIS GBU is the Identity and Biometric Solutions business line (BL) which is in charge of digital identity in a government scale and operate on cards and passports. the IBS BL is divided in three subunits : ID Documents Solutions (IDDS), Digital ID \& Verification Solutions and Public Security. I am assigned to the IDDS subunit as an intern software developer, under the supervision of Adel Djoudi, formal methods expert at Thales. 

\subsection{Background}
In the IDDS subunit, developers work using program analyzers such as Frama-C, a C code analyzer developed by CEA and Inria. This software provides a precise analysis of their code and potential rifts in it by manipulating functional specification in ACSL language. But Frama-C currently does not provide code comprehension and coding features for C and ACSL, some VS Code extensions exist but they are not able to fully satisfy the needs of developers (whyy???).
The goal of this project is to provide a code assistance tool (reecrire sujet dans la convention de stage)

\subsection{The Language Server Protocol}
Developers working in large scale projects often need a code editing environment with the adequate tooling for the specific languages they use in their workspace. Multiple solutions such as Eclipse or IntelliJ IDEA exist for Java projects, as well as other popular programming languages. But the complexity of developing one tool for one language and one specific editor is unreasonable as it forces developers to repeat the same document analysis logic for every code editor or Integrated Development Environement (IDE) with each programming language. 
%To overcome these, a recent solution was developed : the Language Servers.
%Language Servers are servers providing methods that can be called remotely via a client, in our case the editor, execute them and send back the results to the client. Ex : we want to go to the definition of a function by using `Ctrl+Click` on its name, this means the editor will send a request to the language server ordering it to execute the function ``Go to defintion'' and will send back a result in form of a text that will be interpreted by the code editor and then display the definition of the function to the user.
